# Northline Advisory — GitHub Pages Site

This is a complete static website ready for GitHub Pages.

## Files
- `index.html` — Home
- `capability.html` — Capabilities
- `leadership.html` — Leadership
- `styles.css` — Site styling
- `script.js` — Navigation and subtle reveal effects
- `.nojekyll` — Prevents Jekyll processing

## Publish on GitHub Pages
1. Create a GitHub repository.
2. Upload the contents of this folder to the repository root.
3. In GitHub: **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Choose the `main` branch and `/ (root)`.
6. Save.

## Before launch
Search and replace:
- `Northline Advisory` with the final company name.
- `contact@example.com` with the real email address.
- Placeholder leadership names and bios with actual leadership information.

No build system or dependencies are required.
